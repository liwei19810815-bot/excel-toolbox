# 功能清单

共 59 个命令，全部挂在 Excel 的「工具箱」选项卡下。

**可撤销**一列的含义见 [README 的撤销小节](../README.md#撤销)：
标「是」的走统一撤销框架，点工具箱里的撤销按钮可逐步回退（默认保留 5 步，仅当前 Excel 会话有效）；
标「否」的**无法撤销**，其中破坏性的会在执行前强制弹确认框。

---

## 撤销

| 命令 | 说明 |
|---|---|
| 撤销 | 回退上一步工具箱操作。按钮上会直接显示待撤销的操作名 |
| 环境复位 | 宏被强行中断后恢复屏幕刷新、自动重算、事件响应和状态栏 |

## M1 文本处理

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 清除空格 | 是 | 去首尾空格、压缩中间连续空格，并清除不间断空格(U+00A0)、全角空格、零宽字符。这些字符看不见，却是「两个值看着一样却匹配不上」的主因 |
| 文本转数值 | 是 | 文本型数字转真正的数值，自动处理全角数字、千分位逗号、不间断空格。**先把单元格格式改成常规再写值**，否则写进去还是文本 |
| 转大写 / 转小写 / 首字母大写 | 是 | |
| 全角转半角 / 半角转全角 | 是 | 用显式码位映射，不用 `StrConv`（见 README 踩坑第 1 条） |
| 删除换行符 | 是 | 去掉单元格内换行 |
| 只保留数字 / 中文 / 字母 | 是 | 正则提取 |
| 添加前后缀 | 是 | 前缀后缀都可留空 |
| 正则替换 | 是 | 执行前先校验正则是否合法，避免在循环里反复抛错 |
| 按分隔符拆列 | 是 | 先算出需要几列并插入，**不覆盖右侧已有数据**。不用内置的分列，那个受区域设置影响且会静默覆盖 |
| 拆分合并单元格并填充 | 是 | Excel 自带的取消合并只在左上角留值，其余变空；这里填满整个区域 |
| 合并相同项 | 是 | 只合并**相邻且相同**的值，不跨越不同值 |

## M2 数据处理

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 删除空行 / 删除空列 | 是 | 只按选中的行列判空。遇到合并单元格会拒绝执行 |
| 标记重复值 | 是 | 重复行标浅红，支持多列组合判重，不标首次出现的那行 |
| 删除重复值 | 是 | 保留首次出现。判重走 Dictionary 哈希，十万行也是线性 |
| 提取唯一值 | 否 | 输出到新工作表，不改原数据 |
| 两表对比 | 否 | 按键列输出：仅 A 有 / 仅 B 有 / 内容不同。每行带超链接可跳回源数据 |
| 二维转一维 | 否 | 逆透视。透视表、Power Query、数据库都需要一维明细表 |
| 行列转置 | 否 | 只转值，不转公式引用。输出到新表 |

## M3 工作表管理

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 按列拆表 | 否 | 按某列的值拆成多个工作表。表名自动处理 31 字符上限、非法字符和重名 |
| 合并所有表 | 否 | **按标题名对齐**而不是按列位置——某张表少一列也不会整体错位 |
| 生成目录 | 否 | 带超链接的导航表，附每张表的已用区域 |
| 工作表排序 | 否 | 按名称升/降序 |
| 显示所有隐藏表 | 否 | 含「深度隐藏」的表 |
| 按列表批量重命名 | 否 | 先全部改临时名再改目标名，避免中途撞名留下烂摊子 |

## M4 多文件合并

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 合并文件夹 | 否 | 合并文件夹（可递归）内所有 Excel 文件。源文件**只读**打开；单个文件失败不中断整批，最后出失败清单；结果带「来源文件 / 来源工作表」两列 |

## M5 文件批处理

动的是磁盘上的文件，**全部不可撤销**。

| 命令 | 确认 | 说明 |
|---|---|---|
| 生成文件清单 | | 文件名、扩展名、大小、修改时间导入表格，并生成可填写的「新文件名」列 |
| 批量重命名文件 | 强制 | 按清单的 F 列改名。**先全表校验**（源文件在否、文件名合法否、会不会撞已有文件、批内有无重名），全部通过才动手；结果写回 G 列 |
| 导出工作表为文件 | 强制 | 每张表导出为独立 xlsx / CSV(UTF-8) / PDF |
| 批量插入图片 | | 按单元格内容在指定文件夹找同名图片，插入右侧单元格并等比缩放 |

## M6 公式与引用

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 公式转值 | 是 | 不走剪贴板，不会清掉用户的剪贴板内容 |
| 定位错误值 | 是 | 标黄并选中 |
| 套用 IFERROR | 是 | 已有 IFERROR 的会跳过，重复执行不会叠成嵌套 |
| 断开外部链接 | 强制确认 | 链接断了找不回来源 |
| 清理失效名称 | 强制确认 | 删除指向 `#REF!` 的已定义名称——文件体积膨胀和「打开时莫名弹框」的常见原因 |
| 显示/隐藏公式 | 否 | |
| 清理格式规则 | 是 | 清除选区内堆叠的条件格式和数据验证。反复复制粘贴会堆出成百上千条重复规则，表现为文件越来越大、滚动越来越卡 |

## M7 数据体检

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 数据体检 | 否（只读） | 一次扫出：空行、文本型数字、文本型日期、首尾空格/不可见字符、错误值、合并单元格、超长文本。报告每行带超链接可跳转定位；同类问题超过 200 条只列前 200 条 |
| 一键清洗 | 是 | 只做三件无歧义的事：清理空白字符、文本型数字转数值、删除空行。**合并单元格和错误值不碰**——正确处理方式依赖业务语义，自动改很可能改错 |

## M9 辅助增强

| 命令 | 可撤销 | 说明 |
|---|---|---|
| 聚光灯 | 否（开关） | 高亮光标所在整行整列。**用条件格式实现，不会破坏你原有的单元格底色**——直接改 Interior.Color 的做法会永久吃掉原有填充 |
| 金额大写 | 是 | 人民币中文大写，写到右侧一列。正确处理零的各种情形：`10001 → 壹万零壹元整`、`100.05 → 壹佰元零伍分`、`100000000 → 壹亿元整` |
| 身份证解析 | 是 | 出生日期、性别、年龄，并按国标 GB 11643 校验校验位。不验校验位的话随便编一串数字也能「解析」出生日，反而更危险 |
| 日期规范化 | 是 | `20240115` / `2024.1.15` / `2024年1月15日` 统一转成真正的日期值。**先改单元格格式再写值** |
