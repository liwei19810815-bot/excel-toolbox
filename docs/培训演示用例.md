# 业务培训演示用例（讲师用）

面向**给业务人员做培训的人**。一场 45 分钟的课，照着这份讲稿走一遍即可。

演示数据一条命令生成，学员改乱了随时重跑还原：

```bash
powershell -ExecutionPolicy Bypass -File training\New-DemoData.ps1
```

默认生成到桌面的「工具箱培训演示」目录。数据**完全确定**（不含随机数），
所以下面写的行号、客户名、结果数字都能对得上，截图也不会过期。
重跑要加 `-Force`（它会清空目录，默认拒绝覆盖，免得删掉讲师自己的文件）。

---

## 开场（3 分钟）：先让他们疼一下

**别一上来就介绍功能。** 打开 `01_销售明细（脏数据）.xlsx` 的「汇总」表：

| 看到的 | 台词 |
|---|---|
| 数量合计 = **0** | "这个 SUM 公式有错吗？没有。" |
| VLOOKUP = **#N/A** | "这个查找写错了吗？也没有。" |

> "公式都是对的，结果都是错的。这种表你们每周都会收到几份。
> 今天要讲的不是怎么写公式，是怎么让这种表变成能用的表。"

这一步的目的是**建立共鸣**，不要急着给答案。可以问一句"有谁遇到过求和是 0？"——
通常会举一片手。

---

## 场景一（8 分钟）：数据体检 → 一键清洗

**这是整场课最重要的 8 分钟。** 学员只记住这一个功能，培训就值回来了。

1. 切到「销售明细」表，点 **工具箱 → 数据体检**
2. 报告会列出：文本型数字、文本型日期、首尾空格与不可见字符、空行、错误值、合并单元格
3. **点报告里的超链接**，会直接跳到出问题的单元格——这个交互要演出来，
   学员的第一反应通常是"还能点？"
4. 回到数据，点 **工具箱 → 一键清洗**
5. 再切到「汇总」表：**求和变成了正常数字**

讲这几句：

> **一键清洗只做三件无歧义的事**：清理空白字符、文本型数字转数值、删除空行。
>
> **它不碰合并单元格，也不碰错误值。** 不是做不到，是这两样怎么处理
> 取决于你的业务——合并单元格该拆开还是该保留、错误值该填 0 还是该去查，
> 机器猜错的代价比省下的事大。所以这两样体检会报给你，但要你自己决定。

**注意**：清洗后 H 列的 `#VALUE!` 会自己消失——因为它本来就是"文本除以文本"造成的。
这一点值得点一句：很多"错误值"不是真有错，是数据类型不对的连锁反应。

---

## 场景二（5 分钟）：为什么看着一样却匹配不上

这是第二有共鸣的场景，单独拎出来讲。

> **这一段要用没清洗过的数据。** 场景一的「一键清洗」已经把空白字符一并清掉了，
> 所以要么把场景二放到场景一之前讲，要么重跑一次 `New-DemoData.ps1 -Force` 再开一份。

1. 看「销售明细」C3 和「客户对照表」A2
2. 两个都是"北辰科技"，肉眼完全一样
3. 在空白单元格输入 `=LEN(销售明细!C3)` 和 `=LEN(客户对照表!A2)` → **6 和 4**

> "多出来的两个字符是空格和**不间断空格**。后者是从网页、从系统导出时带进来的，
> 它不是空格，肉眼看不出来，删都删不掉——因为你按退格删的是普通空格。"

然后用 **工具箱 → 清除空格**，再看 VLOOKUP 恢复正常。

> 「清除空格」不只是 TRIM。它还清掉不间断空格(U+00A0)、全角空格、零宽字符——
> 这三样是"两个值看着一样却匹配不上"的主要元凶。

## 场景三（4 分钟）：撤销 —— 先建立信任

**这一段不能省。** 业务人员最怕的就是"工具把我数据改坏了，还回不去"。

1. 随便做一个操作（比如「转大写」）
2. 指给他们看：**工具箱的撤销按钮上直接写着"撤销 转大写"**，不用猜上一步做了什么
3. 点一下，数据回去了

必须如实讲清楚边界，不要让他们产生错误预期：

> - Excel 自带的 Ctrl+Z 对**任何宏**都失效，这是 Excel 的机制，不是本工具的缺陷。
>   所以工具箱自己做了一套撤销。
> - **默认保留 5 步**，只在**当前 Excel 会话**内有效——**关掉 Excel 就没了**。
> - 标着**【不可撤销】**的功能（改文件名、导出文件、断开链接）是真的撤不回来，
>   它们执行前会强制弹确认框。**看到确认框就停下来读一遍**。

鼠标悬停在按钮上，提示里会直接写【可撤销】还是【不可撤销】——让他们养成看一眼的习惯。

---

## 场景四（5 分钟）：日期与重复值

**日期规范化**

1. 看 B 列：`20240101` / `2024.1.2` / `2024年1月3日` / `2024-01-04` 四种写法并存
2. 试着按日期排序 → 顺序是乱的（因为它们是文本，按字符串排）
3. **工具箱 → 日期规范化** → 四种写法统一成真正的日期
4. 再排序 → 正常了

> 文本型日期的麻烦不止排序：筛选"本月"筛不出来、做透视表按月汇总会散成几十项。

**重复值**

1. **工具箱 → 标记重复值**，选订单号列 → 重复行标浅红（**首次出现的不标**）
2. 如果确定要删：**工具箱 → 删除重复值**，保留首次出现的那行

> 建议先"标记"看一眼再"删除"。标记是可撤销的，删完了虽然也能撤销，
> 但心里没底的时候先看后删更稳妥。

---

## 场景五（6 分钟）：多文件合并 —— 最省时间的一个

用 `03_分公司数据\` 目录。**先把三个文件打开给他们看一眼**，重点指出：

- 华东：订单号 / 客户 / 金额 / 销售员
- 华南：订单号 / **金额 / 客户** / 销售员 ← 列顺序不一样
- 华北：订单号 / 客户 / 金额 ← **少一列**

> "手工复制粘贴的话，第二个文件列顺序不同，粘过去金额和客户就串了；
> 第三个少一列，后面的数据整体错位。而且错了不会报错，你得自己发现。"

然后 **工具箱 → 合并文件夹**，选这个目录。

结果要讲三点：

1. **按标题名对齐**，不是按列位置——所以列顺序不同、少一列都不会错位
2. 结果自带**「来源文件」「来源工作表」**两列，出了问题能追回去是哪份表
3. 源文件是**只读**打开的，合并不会改动它们

> 单个文件失败不会中断整批，最后会给一份失败清单。

---

## 场景六（5 分钟）：文件批处理 —— 讲风险的一段

用 `04_待重命名文件\`。这一段的重点**不是功能，是风险意识**。

1. **工具箱 → 生成文件清单**，选该目录 → 文件名、大小、修改时间进表，并多出一列"新文件名"
2. 在"新文件名"列填上规范的名字（比如 `报价单_北辰科技_20240105.xlsx`）
3. **工具箱 → 批量重命名文件** → 弹出强制确认框

停在确认框上讲：

> **这一类功能动的是磁盘上的真实文件，撤销按钮救不了你。**
>
> 好消息是它**先全表校验再动手**：源文件在不在、文件名合不合法、会不会撞上已有文件、
> 批内有没有重名——**全部通过才开始改**，不会改到一半留个烂摊子。
>
> 但校验通过不等于你填对了。**改名前先备份一份**，这是习惯问题，不是工具问题。

改完看 G 列的结果回写。

---

## 场景七（4 分钟）：财务与人事的两个小工具

用 `02_员工信息.xlsx`。这两个功能受众窄但共鸣极强。

**金额大写**：选 D 列 → **工具箱 → 金额大写** → 右侧生成人民币中文大写。

可以提一句它把"零"的几种情形都处理对了：`10001 → 壹万零壹元整`、
`100.05 → 壹佰元零伍分`、`100000000 → 壹亿元整`。

**身份证解析**：选 C 列 → **工具箱 → 身份证解析** → 出生日期、性别、年龄。

**重点演第 5 行（周涛）**：它的校验位是错的，工具会**如实报错**，不给结果。

> "不验校验位的工具，随便编一串数字也能给你'解析'出生日期。
> 那不是宽容，那是把错误数据洗成了看起来对的数据，比报错危险得多。"

顺带说明：演示用的这些号码都是**构造的测试数据**，不是真实个人信息。

---

## 收尾（5 分钟）：教会他们自己找功能

**这一段决定培训之后他们还会不会用。**

1. 功能区最右边的 **「我要做什么」搜索框**：按**症状**搜，不用记功能名
   - 打"求和是0" → 找到文本转数值 / 数据体检
   - 打"匹配不上" → 找到清除空格
   - 打"合并文件" → 找到合并文件夹
2. **「帮助」按钮**：每个功能什么时候用、怎么用、有什么坑
3. 命令执行失败时，报错框里会直接问"要不要看对应的帮助"

必须讲这一句（这是设计上的刻意取舍）：

> **搜索框只带你去帮助，不会直接执行命令。**
> 因为工具箱里有删除重复值、批量改名这类会改数据的功能——
> 在输入框打几个字一回车数据就被改了，那不叫方便，那叫危险。

最后告知**使用统计**（这是对员工的承诺，培训时必须说，不能让人事后才发现）：

> 工具会向公司内网上报**用了哪个功能、成功还是失败、耗时**，
> 用来修 bug 和改进产品。
> **不采集**文件内容、文件名、路径、单元格里的任何数据。
> 详见安装目录里的「使用说明.txt」。

## 讲师注意事项

**演示前**

- [ ] 重新生成一遍演示数据（`-Force`），确保是干净的初始状态
- [ ] 确认用的是演示目录里的副本，**不是谁的真实文件**——场景六会真的改磁盘文件
- [ ] 关掉其它 Excel 窗口，避免撤销演示时切错文件

**容易翻车的地方**

| 现象 | 原因 |
|---|---|
| 撤销按钮是灰的 | 上一步操作本身不可撤销，或已经撤到底了（默认 5 步） |
| 重开 Excel 后撤不了了 | 撤销只在当前会话内有效，这是设计如此，要如实讲 |
| 某个按钮点不动 | 当前没有打开工作簿、没选中区域，或选区里有合并单元格 |
| 清洗后错误值没了 | 正常。那些 `#VALUE!` 本来就是文本型数字的连锁反应 |

**不要承诺的事**

- 不要说"所有操作都能撤销"——文件批处理不能
- 不要说"一键清洗能搞定所有脏数据"——它刻意不碰合并单元格和错误值
- 不要说"装上就能用"——公司安全策略整个禁用宏时，任何插件都用不了
