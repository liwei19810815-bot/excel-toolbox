Excel 通用工具箱 —— 安装说明
============================================

【怎么用】

  双击「Excel工具箱.bat」。

  它会先看你装没装，然后问你要做什么：

      没装过  →  直接回车就开始安装
      装过了  →  可以选 重新安装 / 卸载 / 退出

  装和卸都是这一个文件，不用找第二个。

  开始之前请先关闭所有 Excel 窗口。
  忘了关也没关系，程序会等你关，不会替你关（以免弄丢没保存的内容）。

  不需要管理员权限。


【装完没看到「工具箱」选项卡？】

  1. 确认 Excel 完全关闭后重新打开了一次
  2. 如果公司的安全策略把宏整个禁掉了，任何 Excel 插件都用不了，请联系 IT
  3. 机器上装了多套 Office 时，可能装到了另一套上


【使用情况统计】

  本工具会向公司内网服务器上报【功能使用次数】和【出错信息】，
  用于修复问题、分析使用情况、改进产品。上报内容包括：

      用了哪个功能、用的时候成功还是失败、耗时、
      出错时的错误号和错误描述、你的登录名、计算机名、时间

  【不采集】你的文件内容、文件名、文件路径、单元格里的数据。
  这一条在测试里有专门的断言守着，不是口头承诺。

  上报在后台进行，不影响你使用，也不需要你做任何操作。
  服务器不可用时不会有任何提示，更不会影响功能。

  未配置内网收集地址时（例如个人自行下载使用），本功能默认关闭。


【它改了我电脑上的什么？】

  为了让你放心，把动过的东西都列在这里：

  1. 复制一个文件到
       %APPDATA%\Microsoft\AddIns\
     这是 Excel 放加载项的标准位置。

  2. 在 Excel 的加载项列表里勾选它
     等价于你自己走一遍"文件 → 选项 → 加载项 → 转到 → 浏览"。

  3. 把这个目录加进 Excel 的"受信任位置"
       %LOCALAPPDATA%\ExcelToolbox
     不加的话，每次打开 Excel 都会弹一次宏安全警告。
     这一步会改 Excel 的安全设置，程序运行时会明确告诉你。

  除此之外不动任何系统设置，不写系统目录，不需要联网。

  选"卸载"时，上面三项会全部还原，不留痕迹。


【给 IT / 批量部署】

  几十台机器不建议一台台双击。交互式菜单可以用参数跳过：

    powershell -ExecutionPolicy Bypass -File Install-Toolbox.ps1 -Install -NoTrustedLocation
    powershell -ExecutionPolicy Bypass -File Install-Toolbox.ps1 -Uninstall

  -NoTrustedLocation 表示不改 Excel 安全设置。
  批量部署时建议加上它，受信任位置改由组策略统一下发——
  既好管理，将来信息安全审计时也说得清。

  详见仓库里的 docs\部署与自动更新.md。
